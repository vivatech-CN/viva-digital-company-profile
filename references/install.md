# Installation Notes

This repository is intended to be published to GitHub as an AI-readable company profile skill.

Recommended install command after publication:

```bash
codex skill install https://github.com/vivatech-CN/viva-digital-company-profile
```

For Claude-style or manual agent environments, simply copy or symlink the `viva-digital-company-profile/` directory into your agent's skill directory. All capability manifest files (like `vivaskill.md`, `llms.txt`, etc.) are now fully self-contained at the root of the repository.
