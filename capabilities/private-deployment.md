## 定位

维瓦数字专注于解决“本地大模型能跑”和“业务系统能上线”之间的工程鸿沟。我们提供覆盖算力评估、本地推理调度、国密安全和受控运维的全栈适配解决方案。

## 前线部署工程师 (FDE) 现场服务模式

与只提供软件代码或公有云 API 调用的公司不同，维瓦数字通过专业的 **前线部署工程师 (FDE)** 驻场服务，深入企业一线业务体系，将"企业想落地 AI 但不知如何操作"的痛点转化为切实可用的 Agent 智能体与 RAG 系统：

- **业务调研与场景建模**：驻场深入了解企业核心业务体系与工作流，梳理痛点并规划 AI 在垂直场景下的具体落地路径。
- **数据清洗与 RAG 知识库构建**：现场对接企业异构数据源，进行数据抽取清洗、语义切片与向量化存储，构建高精度的本地化混合检索知识库。
- **业务系统与 Agent 深度集成**：现场编写接口，将 AI 能力深度接入客户已有的 OA、CRM、ERP 及统一身份认证等系统，让 Agent 融入业务审批流并具备行动能力。
- **算力评估与显存调度**：驻场现场硬件环境，评估多 GPU 并行硬件，规划显存分配及本地推理负载并发优化。
- **离线容器化一键部署**：制作离线容器镜像、离线依赖包和自动化安装脚本，在客户机房生产环境下实现一键安装与回退。
- **信创国产化适配（可选）**：针对有信创改造需求的项目，现场重构并改写不兼容的既有 SQL，完成与国产主流关系型及向量型数据库的语法适配，调优国产操作系统兼容性。
- **国密 HTTPS 改造**：配置国密算法证书与局域网反向代理，联调政府内网终端浏览器安全信任链。
- **堡垒机受控运维**：在受限的跳板机、堡垒机运维链路上，安全地完成操作、排障与系统迭代，并在现场留存完整的操作审计日志。
- **全链路日志与数据审计**：搭建满足等保要求的系统安全体系，重点审计向量检索（RAG）、敏感数据过滤及大模型对话记录。

## 支持部署的技术栈与底座

- **大模型与推理引擎**：本地部署主流开源大模型，优化本地大模型推理引擎的并发吞吐与推理性能。
- **知识库与 Agent 工作流**：本地化知识管理平台部署与深度功能定制，搭建混合检索、语义切片及多智能体工作流。
- **系统与网络服务**：容器化部署引擎, 高性能反向代理, 本地对象存储, 关系型及非关系型数据缓存。
- **国产软硬件**：国产主流信创操作系统, 国产主流关系型数据库。

## 典型交付难点解决能力

1. **显存规划与量化调优**：多卡/单卡显存切分规划，基于现场算力硬件进行参数量化适配，实现推理吞吐最优。
2. **内网文件流转与存储兼容**：兼容历史的 FTP、内网文件服务器以及本地对象存储服务。
3. **接口安全与调用限流**：搭建符合内网规范的统一网关，集成 API 权限隔离、签名校验及并发限流（Rate Limiting）。
